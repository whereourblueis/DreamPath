# DreamPath

AI 기반 통합형 진로 분석 플랫폼.  
사용자 성향 분석, 진로 추천, 멘토링, AI 어시스턴트를 하나의 서비스에서 제공한다.

## 기술 스택

- React 18, TypeScript, Vite
- Tailwind CSS, React Router, Axios
- OpenAI API, Pinecone (RAG)

## 팀 구성

- Frontend / AI: 1명 (본인)
- Backend / AI: 3명

프론트엔드 전담 + AI 챗봇 풀스택 구현

## 주요 기능

- 사용자 성향 분석 기반 진로 추천
- 비회원 FAQ 챗봇 / 회원 전용 AI 어시스턴트 (RAG 기반)
- 멘토 검색·예약·매칭 시스템
- FAQ 및 사용자/멘토 관리 어드민 대시보드
- 30개+ 페이지 반응형 UI / 시스템 설정 연동 다크모드
## 개발 기간

2025.11.13 ~ 2025.12.19
